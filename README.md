# Acadcalendar

A replica of a capstone project featuring a web0based notification system that alerts students and school stuff through several methods like web alerts, email or SMS.

## Features
- Displays a calendar containing educational events.
- Provides notifications about educational events through web, email or SMS.
- Gives advanced users like teachers to create, edit and delete educational events.

## Tech Stack used in Development

**Frontend**
- HTML
- CSS
- JS
- JQuery

**Backend**
- PHP
- MySQL
- Messagebird API

**Deployment**
- Vercel

## Reflection
This capstone project was a collaboration between me and several classmates back at college. All I did was apply what I learned without relying too much on modern frameworks. It did work in the past when it was hosted at InfinityFree and managed through FileZilla. Regardless, I'll be remaking this when I have the time.
